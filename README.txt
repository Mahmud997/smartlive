## Что исправлено

- `index (1).html` исправлен на `index.html`, поэтому GitHub Pages открывает приложение как главную страницу.
- Авторизация Google через Firebase сохранена.
- Демо-вход сохранён.
- Добавлены фотографии объявления: до 5 фото, предпросмотр, удаление фото до публикации.
- Фото автоматически сжимаются для телефона и сохраняются вместе с объявлением.
- В карточке объявления показывается первое фото.
- Свои объявления можно удалить.
- Избранное работает.
- Такси разделено на режимы **Пассажир / Водитель**.
- Пассажир: Откуда, Куда, геолокация, цена, количество пассажиров, заказ.
- Водитель: профиль машины, выход на линию, получение заказов, принятие заказа, предложение своей цены.
- Статусы поездки: поиск → водитель найден → на месте → поездка → завершена.
- Для вошедших через Google такси использует Firebase Realtime Database для обмена заказами между телефонами.
- Если Firebase Database не настроена, объявления и демо-режим продолжают работать локально.

## Firebase

### 1. Authentication

В Firebase Console включите:

- Authentication
- Sign-in method
- Google

Добавьте домен GitHub Pages в Authorized domains, например:

`ВАШ-ЛОГИН.github.io`

### 2. Realtime Database

Создайте Realtime Database.

В `firebase-taxi.js` уже указан:

`https://smatrlive-default-rtdb.firebaseio.com`

Если Firebase Console создаст другую ссылку, замените значение `databaseURL`.

Для первого теста можно использовать правила:

```json
{
  "rules": {
    "taxiOrders": {
      ".read": "auth != null",
      "$orderId": {
        ".write": "auth != null"
      }
    },
    "drivers": {
      ".read": "auth != null",
      "$uid": {
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}
```

После тестирования рекомендуется сделать правила более строгими.

## Как загрузить на GitHub

1. Создайте репозиторий.
2. Загрузите все файлы из этой папки в корень репозитория.
3. В GitHub откройте Settings → Pages.
4. Выберите Deploy from branch.
5. Выберите `main` и `/ (root)`.
6. Сохраните.
7. Откройте адрес GitHub Pages.

## Важно про фото

Фото объявлений в этой версии сжимаются и сохраняются локально на устройстве. Это позволяет сразу пользоваться приложением без дополнительной настройки Firebase Storage.

Чтобы фотографии одного объявления были доступны **на всех телефонах**, следующим этапом нужно подключить Firebase Storage и хранить URL фотографий в базе.

## Важно про такси

Для реальной работы пассажир и водитель должны входить через Google, потому что Firebase Realtime Database использует авторизованный Firebase UID.

Локальный демо-вход предназначен для проверки интерфейса и функций на одном устройстве.
