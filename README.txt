# Сайрам Live — полная версия

## Файлы
- index.html — интерфейс
- style.css — стили
- app.js — основная логика
- firebase-auth.js — Google/Firebase авторизация
- manifest.webmanifest — PWA
- sw.js — service worker

## Запуск
Можно открыть index.html локально. Для GitHub Pages загрузите все файлы в корень репозитория.
Firebase Google Sign-In требует, чтобы домен GitHub Pages был добавлен в Authorized domains Firebase Authentication.

## Демо-вход
Если Firebase-вход недоступен, кнопка «Продолжить как демо-пользователь» позволяет проверить интерфейс и локальные функции.

## Локальные данные
Объявления, избранное, уведомления и заявки такси сохраняются в localStorage браузера.
